# Reproducibility checklist

- [ ] Replace starter fixtures with independently authored tasks.
- [ ] Verify intended fixes and independent hidden tests.
- [ ] Check model identifiers and current token prices.
- [ ] Pin Docker image by digest for published runs.
- [ ] Freeze split membership and hash the dataset.
- [ ] Predeclare repeats, seeds, thresholds, and exclusions.
- [ ] Keep diagnoser evidence restricted to training attempts.
- [ ] Review accepted rules and suspicious diffs.
- [ ] Freeze rules before one-time sealed evaluation.
- [ ] Report counts, uncertainty, regressions, cost, and audit flags.
